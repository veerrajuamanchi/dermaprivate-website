Optional AI Assist

AI setup

Create a key with Groq, then enter it in the DermaPrivate app’s AI settings.

!

Keep your key private. This website does not collect, store, or display API keys. Never paste a key into a public form, code repository, screenshot, or support email.

Setup steps

  1. Open the Groq API keys console ↗.
  2. Sign in or create a Groq account, then create a new API key.
  3. Copy the key once and keep it in a secure password manager.
  4. Open DermaPrivate and add the key in its AI settings.
  5. Review the approved information and consent prompt before sending any request.

Important boundaries

Your Groq account and provider terms apply. Optional AI Assist is for cosmetic skincare education only. It does not diagnose conditions, prescribe treatment, or change your routine automatically. You decide whether to use AI and whether to act on an explanation.
