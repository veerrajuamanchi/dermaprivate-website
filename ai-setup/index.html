Optional AI Assist

Set up your own AI key.

AI is a separate app option. Read AI and data use first so you can decide whether it fits how you want to use DermaPrivate.

Bring your own Groq key (BYOK). The current iOS release settings use this provider mode. The app stores the key in secure device storage and uses it for provider requests.

Setup steps

  1. Review the app’s AI and data use details, including which request information may be sent.
  2. Open the Groq API keys console ↗ and follow Groq’s current instructions to create a key.
  3. Keep the key in a secure password manager while you use it.
  4. In the app’s AI settings, add the key and review the in-app consent before sending an AI request.

DermaPrivate does not collect a key through this website. A key entered in the mobile app is used by the app to authenticate with Groq’s API.

If you change your mind

AI Assist is optional. You can leave it unconfigured and continue using the app’s routine organization features.

Provider setup instructions can change. Last reviewed: October 14, 2026.
